# RIT ground-truth marking

Paint on each image in `to_mark/` (tools/rit_paint_tool.html):
- IRIS   -> pure RED  (255,0,0) = the dark round iris disc / visible sliver
- SCLERA -> pure BLUE (0,0,255) = the white/pink between the lids (everything in the opening that is not iris)
Together red+blue fill the eye opening; leave lids/lashes/skin blank.
Export the .zip, then run the RIT Learning Workbench on this clip.
