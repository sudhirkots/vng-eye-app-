# EyeVNG

EyeVNG is a modular platform for measuring eye and head movements from smartphone videos for vestibular analysis.

## Current Scope
- Video upload
- Face detection
- Eye tracking
- Head tracking
- Horizontal and vertical eye traces
- CSV export
- Overlay video
- Tracking quality metrics

## Architecture
See [SYSTEM_ARCHITECTURE.md](SYSTEM_ARCHITECTURE.md).

## Notes
Diagnosis and classification are intentionally excluded from Version 1 so the measurement engine can be built first.
